## 环节 1：CubeMX 图形化配置（.ioc 文件）

`Exp1_GPIO_UART_RTC.ioc` 是 CubeMX 的工程描述文件，图形界面里每点一下都落成其中一条键值：

```
Mcu.Name=STM32F407V(E-G)Tx          ← 选型：F407VG，LQFP100 封装
Mcu.Pin3=PA0-WKUP ...               ← 引脚分配表：哪个脚用作什么
RCC.PLLM=8 / PLLN=336 / PLLP=/2     ← 时钟树：PLL 三分频系数（→168 MHz）
RCC.SYSCLKSource=...PLLCLK          ← 系统时钟源选 PLL
RTC.AsynchPrediv=127 / SynchPrediv=249  ← RTC 分频（LSI 32 kHz → 1 Hz）
USART2.BaudRate=9600 / WordLength=8B / StopBits=1 / Parity=None ← 串口参数
ProjectManager.TargetToolchain=MDK-ARM V5.32 ← 生成目标：Keil 工程
ProjectManager.LibraryCopy=1        ← 把 HAL 库拷进工程目录（而非引用）
```

点 GENERATE CODE 后 CubeMX 做三件事：① 生成 `Core/`（初始化代码骨架）；② 拷贝 `Drivers/`（HAL+CMSIS）；③ 生成 `MDK-ARM/xxx.uvprojx`（Keil 工程）。**代码里 `/* USER CODE BEGIN xxx */ ... END */` 标记对内的内容在重新生成时不会被覆盖**——本工程所有应用逻辑都写在标记对内。

时钟树在 CubeMX 图形界面上的换算（Clock Configuration 页）：

```
HSE 8 MHz ─ /M=8 → 1 MHz ─ ×N=336 → 336 MHz ─ /P=2 → SYSCLK 168 MHz
                                            └ /Q=7 → 48 MHz（USB 用）
168 MHz ─ AHB /1 → HCLK 168 MHz
              ├ APB1 /4 → PCLK1 42 MHz（上限 42，不能超）
              └ APB2 /2 → PCLK2 84 MHz（上限 84）
Flash 等待周期：168 MHz@3.3V → 5 WS（HAL 自动配）
```

## 环节 2：上电启动链（startup → system → main）

```
复位 → startup_stm32f407xx.s（汇编，CubeMX 生成，不用改）
       ├ 建立中断向量表（RTC_WKUP/USART2 的入口地址就在这张表里）
       ├ 初始化 .data/.bss 段（全局变量搬运与清零）
       └ 跳转 SystemInit() → main()
system_stm32f4xx.c 的 SystemInit()：复位 RCC 默认值、配置向量表偏移，不配时钟（时钟在 main 里配）
main() 开始执行用户流程
```

## 环节 3：main.c —— 主程序（逐行注释）

```c
/* Includes ------------------------------------------------------------------*/
#include "main.h"     // 总头文件：含 stm32f4xx_hal.h、引脚宏、共享变量声明
#include "rtc.h"      // 声明 MX_RTC_Init() 和 extern hrtc（RTC 句柄）
#include "usart.h"    // 声明 MX_USART2_UART_Init() 和 extern huart2（串口句柄）
#include "gpio.h"     // 声明 MX_GPIO_Init()

/* USER CODE BEGIN Includes */
#include <stdio.h>    // printf / snprintf 需要
#include <string.h>   // strlen 需要
/* USER CODE END Includes */

/* USER CODE BEGIN PD */
#define LED_MARQUEE_PERIOD_MS   200U   // 跑马灯节拍：相邻 LED 点亮间隔 200 ms
#define KEY_DEBOUNCE_MS         20U    // 按键消抖窗口 20 ms（抖动约 5~10 ms）
/* USER CODE END PD */

/* USER CODE BEGIN PV */
volatile uint32_t m_nRtcYMD    = 0U;  // 年月日 YYMMDD，volatile：会被中断修改
volatile uint32_t m_nRtcHMS    = 0U;  // 时分秒 HHMMSS，同上
volatile uint8_t  g_rtcSecFlag = 0U;  // 秒中断→主循环的“有新数据”标志
char              g_rtcString[32] = "RTC init\r\n";  // 中断里格式化好的时间串

/* 四颗 LED 在板上呈菱形：LD3 上 / LD5 右 / LD6 下 / LD4 左。
   按名字 LED3→LED4→LED5→LED6 走会成 Z 字形，
   按物理位置绕圈（上→右→下→左）才是平滑的顺时针。 */
static const uint16_t s_ledRing[4] = {LD3_Pin, LD5_Pin, LD6_Pin, LD4_Pin}; // 序号→引脚（顺时针）
static uint8_t  s_ledIndex   = 0U;    // 当前点亮到环上第几个（0=LD3 上）
static uint8_t  s_marqueeRun = 0U;    // 跑马灯开关：0 停止 / 1 运行
static uint32_t s_ledTick    = 0U;    // 上一次换灯的时刻（HAL_GetTick 毫秒数）
/* USER CODE END PV */

/* USER CODE BEGIN PFP */
static void Led_AllOff(void);         // 四灯全灭
static void Led_Marquee_Step(void);   // 跑马灯走一步
static void Key_Scan(void);           // 按键扫描（含消抖）
/* USER CODE END PFP */

/* USER CODE BEGIN 0 */
#if defined(__CC_ARM)
#pragma import(__use_no_semihosting)  // 声明不用半主机模式（否则脱机运行 printf 会卡死）
struct __FILE { int handle; };        // ARMCC 标准库要求的 FILE 结构桩
FILE __stdout;                        // printf 的输出目标

void _sys_exit(int x) { (void)x; }    // 库要求 stub：程序退出钩子（空实现）
void _ttywrch(int ch) { (void)ch; }   // 库要求 stub：终端输出钩子（空实现）
#endif

int fputc(int ch, FILE *f)            // printf 重定向：库每输出 1 字符调它一次
{
  (void)f;                            // 未用参数，消警告
  HAL_UART_Transmit(&huart2, (uint8_t *)&ch, 1U, HAL_MAX_DELAY);  // 1 字节阻塞发送到 USART2
  return ch;                          // 返回值符合 fputc 约定
}
/* USER CODE END 0 */

int main(void)
{
  HAL_Init();                         // HAL 核心：SysTick 1 ms 时基、NVIC 分组、Flash 接口

  SystemClock_Config();               // ★ 时钟：HSE→PLL→168 MHz（下面有逐行注释）

  MX_GPIO_Init();                     // ★ GPIO：LED 输出/按键输入/PE4 低电平
  MX_RTC_Init();                      // ★ RTC：LSI 时源+1Hz 秒中断（含写初始时间）
  MX_USART2_UART_Init();              // ★ USART2：9600-8-N-1

  /* USER CODE BEGIN 2 */
  printf("\r\n");                     // 先发个空行，对齐显示
  printf("**********************************************\r\n");   // 横幅，开机即证明串口通
  printf("*  STM32F407G-DISC1  Experiment 1            *\r\n");
  printf("*  Clock / GPIO / UART2 / RTC                *\r\n");
  printf("**********************************************\r\n");
  printf("SYSCLK = %lu Hz\r\n", (unsigned long)HAL_RCC_GetSysClockFreq());  // 读回实际系统频率，应=168000000
  printf("HCLK   = %lu Hz\r\n", (unsigned long)HAL_RCC_GetHCLKFreq());      // AHB 总线频率
  printf("PCLK1  = %lu Hz (APB1, max 42 MHz)\r\n", (unsigned long)HAL_RCC_GetPCLK1Freq()); // 42 MHz
  printf("PCLK2  = %lu Hz (APB2, max 84 MHz)\r\n", (unsigned long)HAL_RCC_GetPCLK2Freq()); // 84 MHz
  printf("USART2 : 9600 bps, 8 data bits, 1 stop bit, no parity\r\n");     // 打印串口参数备查
  printf("Press B1 (PA0) to START/STOP the LED marquee (LED3->LED6)\r\n\r\n"); // 操作提示

  if (HAL_UART_Receive_IT(&huart2, &g_uartRxByte, 1U) != HAL_OK)  // 开启“收 1 字节中断”，链式回显的第一环
  {
    Error_Handler();                  // 失败（极少见）则停机，便于发现
  }
  /* USER CODE END 2 */

  /* USER CODE BEGIN WHILE */
  while (1)                           // 主循环（前后台架构的“后台”）
  {
    Key_Scan();                       // ① 按键扫描，处理启动/停止

    if ((s_marqueeRun != 0U) && ((HAL_GetTick() - s_ledTick) >= LED_MARQUEE_PERIOD_MS))
    {                                 // ② 跑马灯到点：运行中 且 距上次换灯≥200 ms
      s_ledTick = HAL_GetTick();      //   记下本次时刻
      Led_Marquee_Step();             //   熄旧灯、点新灯、序号+1
    }

    if (g_rtcSecFlag != 0U)           // ③ 秒中断置了标志？
    {
      g_rtcSecFlag = 0U;              //   先清标志（防重发）
      HAL_UART_Transmit(&huart2, (uint8_t *)g_rtcString,
                        (uint16_t)strlen(g_rtcString), 100U);  // 把时间串发出去（22 字节@9600≈23ms）
    }
    /* USER CODE END WHILE */
  }
  /* USER CODE END 3 */
}
```

### SystemClock_Config —— 168 MHz 的来历（逐行）

```c
void SystemClock_Config(void)
{
  RCC_OscInitTypeDef RCC_OscInitStruct = {0};   // 振荡器配置结构（HSE/PLL 参数）
  RCC_ClkInitTypeDef RCC_ClkInitStruct = {0};   // 总线分频配置结构

  __HAL_RCC_PWR_CLK_ENABLE();                   // 开电源管理外设时钟（下面要动调压器）
  __HAL_PWR_VOLTAGESCALING_CONFIG(PWR_REGULATOR_VOLTAGE_SCALE1);  // 调压器切到 Scale 1——168 MHz 的硬性前提

  RCC_OscInitStruct.OscillatorType = RCC_OSCILLATORTYPE_LSI|RCC_OSCILLATORTYPE_HSE; // 要配 HSE 和 LSI
  RCC_OscInitStruct.HSEState = RCC_HSE_ON;      // 打开外部 8 MHz 晶振
  RCC_OscInitStruct.LSIState = RCC_LSI_ON;      // 打开内部 ~32 kHz（给 RTC 用）
  RCC_OscInitStruct.PLL.PLLState = RCC_PLL_ON;  // 打开主 PLL
  RCC_OscInitStruct.PLL.PLLSource = RCC_PLLSOURCE_HSE;  // PLL 输入选 HSE（不用 HSI：精度差，课件原话）
  RCC_OscInitStruct.PLL.PLLM = 8;               // 8 MHz / 8  = 1 MHz（VCO 输入，规定 1~2 MHz）
  RCC_OscInitStruct.PLL.PLLN = 336;             // 1 MHz × 336 = 336 MHz（VCO 输出）
  RCC_OscInitStruct.PLL.PLLP = RCC_PLLP_DIV2;   // 336 / 2 = 168 MHz → SYSCLK
  RCC_OscInitStruct.PLL.PLLQ = 7;               // 336 / 7 = 48 MHz（USB 时钟，规范配置）
  if (HAL_RCC_OscConfig(&RCC_OscInitStruct) != HAL_OK)  // 写寄存器并等锁相环锁定
  {
    Error_Handler();                            // 超时/失败→停机排查
  }

  RCC_ClkInitStruct.ClockType = RCC_CLOCKTYPE_HCLK|RCC_CLOCKTYPE_SYSCLK
                              |RCC_CLOCKTYPE_PCLK1|RCC_CLOCKTYPE_PCLK2;  // 四个时钟一起配
  RCC_ClkInitStruct.SYSCLKSource = RCC_SYSCLKSOURCE_PLLCLK;  // CPU 时钟源切到 PLL（168 MHz）
  RCC_ClkInitStruct.AHBCLKDivider = RCC_SYSCLK_DIV1;   // AHB /1 → HCLK 168 MHz
  RCC_ClkInitStruct.APB1CLKDivider = RCC_HCLK_DIV4;    // APB1 /4 → 42 MHz（上限就是 42）
  RCC_ClkInitStruct.APB2CLKDivider = RCC_HCLK_DIV2;    // APB2 /2 → 84 MHz（上限 84）

  if (HAL_RCC_ClockConfig(&RCC_ClkInitStruct, FLASH_LATENCY_5) != HAL_OK)  // 应用分频+Flash 5 等待周期
  {                                                   // （168 MHz 下不插等待周期会取指错误）
    Error_Handler();
  }
}
```

### 三个应用函数（逐行）

```c
static void Led_AllOff(void)
{
  HAL_GPIO_WritePin(GPIOD, LD3_Pin | LD4_Pin | LD5_Pin | LD6_Pin, GPIO_PIN_RESET);
}   // 一次写四个引脚为 0（低电平=灭，板上 LED 高电平点亮）

static void Led_Marquee_Step(void)
{
  Led_AllOff();                                          // 先全灭（保证同一时刻只有一盏亮）
  HAL_GPIO_WritePin(GPIOD, s_ledRing[s_ledIndex], GPIO_PIN_SET);  // 点亮寄存器里当前序号那盏

  s_ledIndex++;                                          // 序号前进（顺指针绕圈）
  if (s_ledIndex >= 4U)                                  // 走完一圈（上→右→下→左）
  {
    s_ledIndex = 0U;                                     // 回到 LED3，循环
  }
}

static void Key_Scan(void)
{
  static uint8_t  s_lastLevel = 0U;    // 记住上次的电平（识别“变化沿”）
  static uint32_t s_keyTick   = 0U;    // 记住上次电平变化的时刻（消抖基准）

  uint8_t nowLevel = (HAL_GPIO_ReadPin(B1_GPIO_Port, B1_Pin) == GPIO_PIN_SET) ? 1U : 0U;
  // 读 PA0：配了下拉，松手=低，按下=高

  if ((nowLevel != s_lastLevel) && ((HAL_GetTick() - s_keyTick) >= KEY_DEBOUNCE_MS))
  {   // 电平确实变了，且距上次变化已过 20 ms → 认定是真实的按下/松开（不是抖动）
    s_keyTick   = HAL_GetTick();       // 刷新时刻
    s_lastLevel = nowLevel;            // 刷新电平

    if (nowLevel != 0U)                // 只响应“按下沿”，松手不动作
    {
      s_marqueeRun = (s_marqueeRun != 0U) ? 0U : 1U;  // 运行/停止取反
      if (s_marqueeRun == 0U)          // 停止时
      {
        Led_AllOff();                  // 顺手把灯全灭（视觉上干净）
      }
      printf("[KEY] marquee %s\r\n", (s_marqueeRun != 0U) ? "RUN" : "STOP");  // 串口报告动作
    }
  }
}
```

### Error_Handler / printf 链路说明

```c
void Error_Handler(void)
{
  __disable_irq();     // 关全局中断（防止半初始化状态再出幺蛾子）
  while (1) { }        // 死循环停机——调试时用断点/示波器定位
}
```

printf 的完整链路：`printf` → ARMCC 库 → `fputc(ch)` → `HAL_UART_Transmit` → USART2 移位寄存器 → TX 引脚 → USB 转 TTL → 电脑 COM11。

## 环节 4：gpio.c —— 引脚初始化（逐行）

```c
void MX_GPIO_Init(void)
{
  GPIO_InitTypeDef GPIO_InitStruct = {0};   // GPIO 配置结构

  __HAL_RCC_GPIOE_CLK_ENABLE();             // PE4 要用，开 GPIOE 时钟
  __HAL_RCC_GPIOH_CLK_ENABLE();             // PH0/PH1（HSE 晶振脚）时钟
  __HAL_RCC_GPIOA_CLK_ENABLE();             // PA0 按键、PA2/PA3 串口
  __HAL_RCC_GPIOD_CLK_ENABLE();             // PD12~15 四个 LED

  HAL_GPIO_WritePin(COM_GND_GPIO_Port, COM_GND_Pin, GPIO_PIN_RESET);  // PE4 先写低
  HAL_GPIO_WritePin(GPIOD, LD4_Pin|LD3_Pin|LD5_Pin|LD6_Pin, GPIO_PIN_RESET);  // 四灯先灭

  GPIO_InitStruct.Pin = COM_GND_Pin;        // 配 PE4：
  GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;   // 推挽输出
  GPIO_InitStruct.Pull = GPIO_NOPULL;           // 不上下拉
  GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;  // 低速（50MHz 足够）
  HAL_GPIO_Init(COM_GND_GPIO_Port, &GPIO_InitStruct);   // 应用：当串口线备用地

  GPIO_InitStruct.Pin = B1_Pin;             // 配 PA0 按键：
  GPIO_InitStruct.Mode = GPIO_MODE_INPUT;   // 纯输入（本实验用扫描，不用中断）
  GPIO_InitStruct.Pull = GPIO_PULLDOWN;     // 下拉！松手稳定为低，按下才为高（防悬空乱跳）
  HAL_GPIO_Init(B1_GPIO_Port, &GPIO_InitStruct);

  GPIO_InitStruct.Pin = LD4_Pin|LD3_Pin|LD5_Pin|LD6_Pin;  // 配 PD12~15：
  GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;   // 推挽输出
  GPIO_InitStruct.Pull = GPIO_NOPULL;
  GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;  // LED 翻转不需要高速
  HAL_GPIO_Init(GPIOD, &GPIO_InitStruct);
}
```

## 环节 5：usart.c —— 串口配置与回显（逐行）

```c
uint8_t g_uartRxByte = 0U;            // 接收缓冲：中断方式收 1 字节放这里

void MX_USART2_UART_Init(void)
{
  huart2.Instance = USART2;           // 句柄绑定到 USART2 外设
  huart2.Init.BaudRate = 9600;        // 波特率 9600（实验要求）
  huart2.Init.WordLength = UART_WORDLENGTH_8B;   // 数据位 8
  huart2.Init.StopBits = UART_STOPBITS_1;        // 停止位 1
  huart2.Init.Parity = UART_PARITY_NONE;         // 无校验
  huart2.Init.Mode = UART_MODE_TX_RX;            // 收发都开
  huart2.Init.HwFlowCtl = UART_HWCONTROL_NONE;   // 无硬件流控（没有 RTS/CTS 线）
  huart2.Init.OverSampling = UART_OVERSAMPLING_16;  // 16 倍过采样（标准）
  if (HAL_UART_Init(&huart2) != HAL_OK)          // 应用配置（内部算 BRR 分频=27，即 0x1117）
  {
    Error_Handler();
  }
}

void HAL_UART_MspInit(UART_HandleTypeDef* uartHandle)   // 底层初始化：HAL_UART_Init 内部回调它
{
  GPIO_InitTypeDef GPIO_InitStruct = {0};
  if(uartHandle->Instance==USART2)
  {
    __HAL_RCC_USART2_CLK_ENABLE();    // 开 USART2 外设时钟（PCLK1 42 MHz 域）
    __HAL_RCC_GPIOA_CLK_ENABLE();     // 开 GPIOA 时钟
    GPIO_InitStruct.Pin = USART2_TX_Pin|USART2_RX_Pin;   // PA2、PA3
    GPIO_InitStruct.Mode = GPIO_MODE_AF_PP;              // 复用推挽（引脚交给 USART 外设驱动）
    GPIO_InitStruct.Pull = GPIO_PULLUP;                  // 上拉：空闲电平为高（UART 空闲态规定为高）
    GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_VERY_HIGH;   // 高速档（串口翻转快）
    GPIO_InitStruct.Alternate = GPIO_AF7_USART2;         // 复用功能号 AF7 = USART2
    HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);

    HAL_NVIC_SetPriority(USART2_IRQn, 1, 0);  // 抢占优先级 1（低于 RTC 的 0，保证计时优先）
    HAL_NVIC_EnableIRQ(USART2_IRQn);          // 使能串口中断线
  }
}

void HAL_UART_RxCpltCallback(UART_HandleTypeDef *uartHandle)  // 收满 1 字节 HAL 回调它
{
  if (uartHandle->Instance == USART2)
  {
    HAL_UART_Transmit(&huart2, &g_uartRxByte, 1U, 10U);  // 原样发回（回显）→ 完成收发测试要求
    HAL_UART_Receive_IT(&huart2, &g_uartRxByte, 1U);     // 再挂下一次接收（链式：收→发→收→…）
  }
}

void HAL_UART_ErrorCallback(UART_HandleTypeDef *uartHandle)   // 出错（如溢出 ORE）时回调
{
  if (uartHandle->Instance == USART2)
  {
    __HAL_UART_CLEAR_OREFLAG(uartHandle);      // 清溢出标志
    HAL_UART_Receive_IT(&huart2, &g_uartRxByte, 1U);  // 重新挂接收，避免“失联”
  }
}
```

## 环节 6：rtc.c —— RTC 与秒中断（逐行）

```c
RTC_HandleTypeDef hrtc;               // RTC 句柄（中断函数也要用，全局）

void MX_RTC_Init(void)
{
  hrtc.Instance = RTC;                // 句柄绑定 RTC 外设（在备份域，VDD 掉电靠 VBAT 维持）
  hrtc.Init.HourFormat = RTC_HOURFORMAT_24;   // 24 小时制
  hrtc.Init.AsynchPrediv = 127;       // 异步分频 128：32000/128 = 250 Hz
  hrtc.Init.SynchPrediv  = 249;       // 同步分频 250：250/250   = 1 Hz（日历计数时钟）
  hrtc.Init.OutPut = RTC_OUTPUT_DISABLE;      // 不用 RTC 引脚输出
  hrtc.Init.OutPutPolarity = RTC_OUTPUT_POLARITY_HIGH;   // （保留默认）
  hrtc.Init.OutPutType = RTC_OUTPUT_TYPE_OPENDRAIN;      // （保留默认）
  if (HAL_RTC_Init(&hrtc) != HAL_OK)  // 应用配置；内部会解锁备份域写保护（DBP 位）
  {
    Error_Handler();
  }
  /* USER CODE BEGIN RTC_Init 2 */
  {
    RTC_TimeTypeDef sTime = {0};      // 时间结构
    RTC_DateTypeDef sDate = {0};      // 日期结构

    sTime.Hours          = 9U;        // 初始 09:00:00（给个确定起点）
    sTime.Minutes        = 0U;
    sTime.Seconds        = 0U;
    sTime.DayLightSaving = RTC_DAYLIGHTSAVING_NONE;   // 不用夏令时
    sTime.StoreOperation = RTC_STOREOPERATION_RESET;  // （保留默认）
    if (HAL_RTC_SetTime(&hrtc, &sTime, RTC_FORMAT_BIN) != HAL_OK)  // 写时间（二进制格式）
    {
      Error_Handler();
    }

    sDate.WeekDay = RTC_WEEKDAY_FRIDAY;   // 2025-11-07 恰是星期五
    sDate.Month   = RTC_MONTH_NOVEMBER;   // 11 月
    sDate.Date    = 7U;                   // 7 日
    sDate.Year    = 25U;                  // 年存后两位：2025→25
    if (HAL_RTC_SetDate(&hrtc, &sDate, RTC_FORMAT_BIN) != HAL_OK)  // 写日期
    {
      Error_Handler();
    }

    if (HAL_RTCEx_SetWakeUpTimer_IT(&hrtc, 0U, RTC_WAKEUPCLOCK_CK_SPRE_16BITS) != HAL_OK)
    {   // ★ 秒信号：唤醒定时器时钟选 ck_spre（正好 1 Hz），重装值 0 → 计 1 个数即中断 = 每 1 秒
      Error_Handler();
    }
  }
  /* USER CODE END RTC_Init 2 */
}

void HAL_RTC_MspInit(RTC_HandleTypeDef* rtcHandle)   // 底层：RTC 时源选择 + 中断使能
{
  RCC_PeriphCLKInitTypeDef PeriphClkInitStruct = {0};
  if(rtcHandle->Instance==RTC)
  {
    PeriphClkInitStruct.PeriphClockSelection = RCC_PERIPHCLK_RTC;  // 要配 RTC 的时钟源
    PeriphClkInitStruct.RTCClockSelection = RCC_RTCCLKSOURCE_LSI;  // 选 LSI——板上没焊 32.768k 晶振，LSE 不可用
    if (HAL_RCCEx_PeriphCLKConfig(&PeriphClkInitStruct) != HAL_OK) // 写备份域（内部先开 DBP 写保护）
    {
      Error_Handler();
    }
    __HAL_RCC_RTC_ENABLE();           // 时钟源选好后才使能 RTC（顺序反了写 BDCR 无效）
    /* USER CODE BEGIN RTC_MspInit 1 */
    HAL_NVIC_SetPriority(RTC_WKUP_IRQn, 0, 0);  // 抢占优先级 0 = 最高：1 Hz 计时不能被串口打断
    HAL_NVIC_EnableIRQ(RTC_WKUP_IRQn);          // 使能唤醒中断线
    /* USER CODE END RTC_MspInit 1 */
  }
}

void HAL_RTCEx_WakeUpTimerEventCallback(RTC_HandleTypeDef *rtcHandle)  // ★ 每 1 秒进一次
{
  RTC_TimeTypeDef sTime = {0};
  RTC_DateTypeDef sDate = {0};

  if (HAL_RTC_GetTime(rtcHandle, &sTime, RTC_FORMAT_BIN) != HAL_OK)  // 读时间
  {                                   // ★ 顺序铁律：必须先读时间再读日期
    return;                           //   （读日期寄存器才会解锁影子寄存器，反着读值不更新）
  }
  if (HAL_RTC_GetDate(rtcHandle, &sDate, RTC_FORMAT_BIN) != HAL_OK)  // 再读日期
  {
    return;
  }

  m_nRtcYMD = (uint32_t)sDate.Year * 10000U + (uint32_t)sDate.Month * 100U + sDate.Date;
  // 25,11,7 → 251107（指导书要求的变量）
  m_nRtcHMS = (uint32_t)sTime.Hours * 10000U + (uint32_t)sTime.Minutes * 100U + sTime.Seconds;
  // 9,0,1  → 90001

  (void)snprintf(g_rtcString, sizeof(g_rtcString),       // 格式化成 "2025-11-07 09:00:01\r\n"
                 "20%02lu-%02lu-%02lu %02lu:%02lu:%02lu\r\n",
                 (unsigned long)sDate.Year, (unsigned long)sDate.Month, (unsigned long)sDate.Date,
                 (unsigned long)sTime.Hours, (unsigned long)sTime.Minutes, (unsigned long)sTime.Seconds);
  // snprintf（非 sprintf）防越界；-snprintf 忽略返回值，消编译警告

  g_rtcSecFlag = 1U;                  // 置标志就走人——串口发送留给主循环
}                                     // （22 字节@9600 要 23ms，在中断里发太奢侈）
```

## 环节 7：stm32f4xx_it.c —— 中断入口（关键三条）

中断硬件链：**外设事件 → NVIC → 向量表 → IRQHandler → HAL_xxx_IRQHandler → 回调**。

```c
void SysTick_Handler(void)      // SysTick 1ms 中断（HAL_Init 配的）
{
  HAL_IncTick();                // 全局毫秒计数 +1 → HAL_GetTick()/HAL_Delay 的时基
}

void USART2_IRQHandler(void)   // 串口中断入口（向量表第 53 号）
{
  HAL_UART_IRQHandler(&huart2);          // HAL 统一处理：判 RXNE/TXE/ORE 等标志，
}                                        // 收满 1 字节则调 RxCpltCallback（回显）

void RTC_WKUP_IRQHandler(void) // RTC 唤醒中断入口（USER CODE 段内实现，重新生成不丢）
{
  HAL_RTCEx_WakeUpTimerIRQHandler(&hrtc);  // HAL 清 WUTF 标志，
}                                          // 调 WakeUpTimerEventCallback（读时间+格式化+置标志）
```

两条中断的优先级设计：RTC_WKUP=抢占 0（最高），USART2=抢占 1。若反过来，23 ms 的串口发送会推迟秒中断，时间就不准了。

## 环节 10：编译 → 烧录 → 测试 三步链

**编译**：`UV4 -r` → ARMCC 逐文件编译（22 个 .c）→ armlink 链接 → `.axf` → fromelf 出 `.hex/.bin`。
结果：`0 Error(s), 0 Warning(s)`，Code 9362 B（Flash 1M 的 0.9%）。

**烧录**（两种都验证过）：
1. 拖拽：把 `Exp1_GPIO_UART_RTC.bin` 拷到 `DIS_F407VG`（E:）盘 → DAPLink 固件自动写入 Flash 并复位运行；
2. Keil F8：走 ST-LINK 调试通道（首次需在 Options→Debug 选 ST-Link Debugger）。

**测试链**（已全部上板验证）：
```
串口输出频率值 → 证明时钟树 168 MHz 正确（SWD 读 RCC 寄存器双重确认）
每秒一行时间   → 证明 RTC 秒中断 + 字符串格式化 + 串口发送链路正确
[KEY] RUN/STOP → 证明按键消抖扫描 + GPIO 输出正确
发 ABC123 回显 → 证明 USART 接收中断链路正确
```

**三个刻意的设计决策**（报告里可以写）：
1. **中断/主循环分工**：秒中断只“读时间+格式化+置标志”，串口发送放主循环——避免 23 ms 发送阻塞高优先级中断；
2. **printf 不用 MicroLIB 而用 no_semihosting**：CubeMX 重新生成代码不会失效，且标准库功能更全；
3. **按键用扫描而非中断**：实验一只要求“按键输入”，扫描+消抖已满足；EXTI 中断留给实验二（任务书实验二明确要求中断方式）。
